Plentovo email signatures

Generated from markets.json (add a country there, re-run the build). Text only: no images. Colours are Plentovo red and near-black. Press Copy signature, then paste into the Gmail signature box.

Putting them into Gmail

  1. Gmail → Settings → See all settings → General → Signature → Create new. Name it after the address, e.g. "Plentovo Accounts".
  2. Click Copy signature above, click into the signature box, paste (Cmd+V). Colours and links come across.
  3. Repeat for each of the others (Sbusiso, Compliance, Support, Hello, Suppliers, Orders, Returns, Sales, Partners, Press, Careers, and the four Tunisia ones in French and Arabic).
  4. Under Signature defaults choose Plentovo Accounts for new emails and for replies/forwards. Save changes at the bottom.
  5. Then Accounts → Send mail as → edit info on each address row and set the sender name to match (e.g. "Plentovo Support").
